### حالة الإنجاز حسب الدور

| الدور | صفحات UI | Write Ops فعّالة | التقييم |
|-------|----------|----------------|---------|
| **المندوب** | 18 صفحة | 3 خدمات حقيقية (فواتير، تحصيل، مرتجعات) + 1 تحويل مخزون | **75%** |

| **الإدارة العليا** | 35 صفحة | 10 خدمات حقيقية | **65%** |

### أكبر 5 ثغرات حرجة

1. **لا توجد ربحية صافية لكل مندوب** — التكاليف التشغيلية (راتب، سكن، وقود) غير مُعرّفة
2. **المتابعة اللحظية وهمية** — GPS عشوائي، لا خريطة حقيقية
3. **كل عمليات الكتابة في المشرف وهمية** — 32 صفحة بـ 0 عملية حقيقية
4. **لا يوجد تصدير تقارير** — كل أزرار Export تظهر toast فقط
5. **البيانات لا تتذكر** — إغلاق المتصفح يفقد كل التغييرات

## 6. تحليل الربحية ومراجعة الحسابات

### 6.1 ما هو موجود

| الميزة | الحالة | التفاصيل |
|--------|--------|---------|
| ربح لكل مندوب | ✅ | `revenue - cost` (COGS فقط) |
| هامش لكل مندوب | ✅ | margin % |
| مقارنة شهرية | ✅ | Bar chart + Line chart |
| 3 عروض (مندوب/موزع/مسؤول) | ✅ | view toggle |
| نطاق حسب الدور | ✅ | فلتر حسب scope |

### 6.2 ما هو مفقود — ثغرة حرجة

```
الربح الصافي لكل مندوب = الإيرادات - تكلفة المنتجات - التكاليف التشغيلية

ما هو موجود:
  ✅ الإيرادات (revenue)
  ✅ تكلفة المنتجات (cost = COGS)

ما هو مفقود (التكاليف التشغيلية):
  ❌ الراتب الشهري
  ❌ بدل السكن
  ❌ بدل الوقود (الثابت — ليس الميداني)
  ❌ بدل الاتصالات
  ❌ التأمينات الاجتماعية
  ❌ تكاليف المركبة (إيجار/صيانة)
  ❌ تكاليف مشاركةOverhead
```

### 6.3 النموذج المقترح للربحية الصافية

```typescript
interface RepProfitability {
  repId: string;
  period: string;
  
  // الإيرادات
  grossRevenue: number;
  returnsAmount: number;
  discountsAmount: number;
  netRevenue: number;
  
  // التكاليف المباشرة
  cogs: number;                    // تكلفة المنتجات المباعة
  tripExpenses: number;            // مصاريف الجولة (وقود ميداني + موقف + وجبات)
  
  // التكاليف الثابتة (شهرية)
  salary: number;                  // الراتب الأساسي
  housingAllowance: number;        // بدل السكن
  fuelAllowance: number;           // بدل الوقود الثابت
  phoneAllowance: number;          // بدل الاتصالات
  vehicleCost: number;             // إيجار/صيانة المركبة
  insurance: number;               // التأمينات
  
  // الحسابات
  grossProfit: number;             // netRevenue - cogs
  operatingProfit: number;         // grossProfit - tripExpenses
  netProfit: number;               // operatingProfit - التكاليف الثابتة
  margin: number;                  // netProfit / netRevenue * 100
  roi: number;                     // netProfit / totalCosts * 100
}
```
