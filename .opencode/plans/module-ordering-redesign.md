## المشكلة الحالية

| مشكلة | التفاصيل |
|-------|---------|
| **8 أقسام** في الـ Sidebar | كثيرة جداً — تسبب التمرير الزائد |
| "ميدان المندوب" فيها **15 صفحات** مسطحة | إرهاق بصري — المستخدم يضيع |
| "المخزون والمالية" تخلط مخزون + مالية | فصل غير منطقي |
| "التوزيع" فيها **2 عناصر فقط** | قسم صغير جداً بلا مبرر |
| "الاعتماد والتحليل" تخلط اعتماد + ربحية + عمولات + تقارير | خلط بين أنشطة مختلفة |
| لا يوجد ترتيب حسب **دورة حياة العملية التجارية** | مختلفة عن SAP و Oracle و Dynamics |

## التحسينات العرضية (Display Improvements)

### 1. Sidebar Design

| التحسين | التفاصيل |
|---------|---------|
| **Frosted glass sidebar** | `backdrop-filter: blur(12px)` + خلفية شبه شفافة |
| **Active indicator bar** | شريط ملوّن على اليسار (موجود — يبقى) |
| **Icons ملونة حسب القسم** | كل قسم له لون خاص |
| **Section dividers رفيعة** | فاصل بصري خفيف بين الأقسام |
| **Badge حمراء** | للموافقات المعلقة + الإشعارات |
| **Hover animation** | تأثير hover ناعم + تغيّر لون الأيقونة |
| **Footer مبسّط** | دور المستخدم + زر طي القائمة فقط |

### 2. Header Improvements

| التحسين | التفاصيل |
|---------|---------|
| **Quick Actions dropdown** | "+" button — إضافة سريعة (عميل، فاتورة، تحصيل) |
| **Search Command Palette** | `Ctrl+K` يفتح نافذة بحث شاملة (مشابه لـ Linear) |
| **Notification badges محسّنة** | تصنيف حسب الأولوية + عدّاد واضح |

### 3. Color Coding للأيقونات

```css
/* المبيعات — أزرق */
color: #2f6fa8 (المبيعات، العملاء، المنتجات)

/* المخزون — برتقالي */
color: #c2700e (المخزون، التحويلات، الطلبات)

/* الميدان — أخضر */
color: #2f7d4f (الميدان، الزيارات، GPS)

/* المالية — بنفسجي */
color: #7c3aed (الصندوق، التحصيل)

/* الإدارة — رمادي */
color: #64748b (الإعدادات، المستخدمين، السياسات)

/* التنبيهات — أحمر */
color: #b3403a (الإشعارات العاجلة، الديون المتأخرة)
```
